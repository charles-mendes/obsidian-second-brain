Em vez de aprender:

> **I + want + to + know**

você aprende o bloco inteiro:

> **I want to know...** = “Eu quero saber...”

### Exemplos de chunks muito usados

| Chunk                        | Significado                           |
| ---------------------------- | ------------------------------------- |
| **I think that...**          | Eu acho que...                        |
| **I don't think so.**        | Eu não acho.                          |
| **I'm not sure if...**       | Não tenho certeza se...               |
| **It depends on...**         | Depende de...                         |
| **As far as I know...**      | Até onde eu sei...                    |
| **What do you mean?**        | O que você quer dizer?                |
| **Let me see...**            | Deixa eu ver...                       |
| **Give me a second.**        | Me dá um segundo.                     |
| **I'm looking for...**       | Estou procurando...                   |
| **I'm trying to...**         | Estou tentando...                     |
| **I need to...**             | Eu preciso...                         |
| **I'd like to...**           | Eu gostaria de...                     |
| **Would you mind...?**       | Você se importaria de...?             |
| **Do you want me to...?**    | Você quer que eu...?                  |
| **I'm used to...**           | Estou acostumado a...                 |
| **It turns out that...**     | Acontece que... / Descobriu-se que... |
| **The thing is...**          | A questão é que...                    |
| **By the way...**            | A propósito...                        |
| **At the end of the day...** | No fim das contas...                  |
| **As soon as possible.**     | O mais rápido possível.               |
