# Tópico: comparatives (-er / more / the most)

Lido pela skill /english-drill quando a sessão usa este tópico. Explicações em português, exemplos em inglês.

- Palavra curta (1 sílaba, ou 2 terminando em -y): **-er / the -est**: *fast → faster → the fastest* · *easy → easier → the easiest* · *big → bigger* (dobra a consoante).
- Palavra longa (2+ sílabas): **more / the most**: *expensive → more expensive → the most expensive* · *important → more important.*
- Irregulares para decorar: *good → better → the best* · *bad → worse → the worst* · *far → farther/further* · *much/many → more → the most* · *little → less → the least*.
- Comparar usa **than**: *Python is easier **than** Java* (não *that* nem *of*). Igualdade: *as fast as*.
- Erros típicos de brasileiro: *more better*, *more easy*, *the most good*, *more fast*; *bigger that*; esquecer o *the* no superlativo (*She is best developer* → *the best developer*).
- Exemplos de adulto: *This laptop is faster than my old one* · *The new church building is bigger than the old one* · *This is the worst bug I've seen.*
