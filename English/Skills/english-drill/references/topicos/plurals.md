# Tópico: plurals

Lido pela skill /english-drill quando a sessão usa este tópico. Explicações em português, exemplos em inglês.

- Regra: +s, +es (*boxes, watches*), consoante + y → -ies (*city → cities*, mas *day → days*).
- Irregulares para decorar: *man → men, woman → women, child → children, person → people, foot → feet, tooth → teeth, mouse → mice*. Iguais no plural: *fish, sheep, series*.
- **Incontáveis** não têm plural nem *a/an*: *information, advice, news, money, furniture, homework, equipment, software, feedback, bread*. Erros típicos de brasileiro: *advices, informations, softwares, an advice*. Para contar: *a piece of advice, two pieces of information*.
- *much* com incontável (*much money*), *many* com contável (*many people*). *people* já é plural: *People **are*** (não *People is*).
- Depois de *every / each*, singular: *every day, each person*.
