# Tópico: continuous (Present Continuous x Simple Present)

Lido pela skill /english-drill quando a sessão usa este tópico. Explicações em português, exemplos em inglês.

- **Simple Present** = rotina, hábito, verdade: *I work from home on Fridays* · *The service starts at 7 PM.*
- **Present Continuous** (*am/is/are + -ing*) = acontecendo **agora** ou neste período: *I'm fixing a bug right now* · *We're working on a new project this month.*
- Palavras-pista: *now, right now, at the moment, today, this week* → continuous · *every day, usually, always, on Sundays* → present.
- Também serve para **planos marcados**: *I'm meeting the client tomorrow at 10.*
- Verbos de estado **não** vão para o -ing: *know, like, want, need, understand, believe, belong* → *I know the answer* (não *I'm knowing*), *I need help* (não *I'm needing*).
- Erros típicos de brasileiro: esquecer o *be* (*I working now* → *I'm working now*); usar continuous para rotina (*I'm going to church every Sunday* → *I go to church every Sunday*); *I'm loving it* em contexto formal.
- Ortografia do -ing: *make → making* (tira o -e), *run → running, get → getting* (dobra a consoante), *lie → lying*.
