# Falsos cognatos (para brasileiro)

Lido pela skill /english-drill em toda sessão (ver "Alerta de falso cognato" no SKILL.md). Em questões de tradução PT → EN, inclua de vez em quando uma frase que teste um destes.

| Inglês | Significa | Parece, mas não é | Para dizer isso, use |
|---|---|---|---|
| *actually* | na verdade | atualmente | *currently, nowadays* |
| *eventually* | no fim | eventualmente | *sometimes, occasionally* |
| *pretend* | fingir | pretender | *intend, plan* |
| *push* | empurrar | puxar | *pull* |
| *parents* | pais | parentes | *relatives* |
| *library* | biblioteca | livraria | *bookstore* |
| *college* | faculdade | colégio | *school* |
| *assist* | ajudar | assistir | *watch* |
| *exquisite* | requintado | esquisito | *weird* |
| *lunch* | almoço | lanche | *snack* |
| *costume* | fantasia | costume | *habit* |
| *realize* | perceber | realizar | *carry out, achieve* |
