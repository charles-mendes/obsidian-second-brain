# Pronúncia "como brasileiro lê"

Lido pela skill /english-drill em **toda** sessão. Mostra a pronúncia com letras do português.
⚠️ É sempre uma **aproximação**: serve para não ler a palavra "em português", não substitui ouvir um nativo. Diga isso ao aluno na 1ª vez em cada sessão (`🔊 (aproximação)`).

## Formato

- Linha `🔊` só com as **palavras-chave** da questão ou da correção: `🔊 paid (pêid) · bill (bíl) · left (léft)`.
- Se o aluno escrever **"pronúncia"**, mostre a frase inteira.
- Alerta de irregular: mostre as duas formas: `think (thínk) → thought (thót)`.

## Convenções

| Convenção | Como escrever | Exemplos |
|---|---|---|
| Sílaba tônica | MAIÚSCULAS, só em palavras com 2+ sílabas | computer (kâm-PIU-târ) · meeting (MÍI-tin) |
| Som fraco/abafado (schwa) | `â` | the (dhâ) · about (â-BÁUT) · problem (PRÓ-blâm) |
| r | sempre r "caipira", nunca o r de "rato" | work (uârk) · car (kár) · read (ríid) |
| th surdo | `th`: língua entre os dentes, só sopra | think (thínk) · thank (thénk) · three (thríi) |
| th sonoro | `dh`: língua entre os dentes, vibra | the (dhâ) · this (dhís) · mother (MÂ-dhâr) |
| i longo | `ii`: "i" esticado | leave (líiv) x live (lív) · sheep (xíip) x ship (xíp) · meet (míit) |
| Sem "i" extra no fim | a palavra acaba na consoante | bill = bíl (não bíli) · like = láik (não láiki) · church = tchârtch (não tchârtchi) |
| Letras mudas | avise qual letra é muda | knew (nú, k mudo) · receipt (ri-SÍIT, p mudo) · listen (LÍ-sân, t mudo) · write (ráit, w mudo) |
| -ed /t/ | depois de som surdo (k, p, s, x, tch, f) | worked (uârkt) · stopped (stópt) · watched (uótcht) |
| -ed /d/ | depois de som vibrado (vogal, l, n, m, r, b, g, v) | played (plêid) · called (kóld) · cleaned (klíind) |
| -ed /id/ | só depois de t ou d: ganha uma sílaba | wanted (UÓN-tid) · needed (NÍI-did) · started (STÁR-tid) |

## Armadilhas de leitura (⚠️ Não leia como em português)

Quando uma destas aparecer, avise: `⚠️ Não leia como em português: said (séd).`

| Palavra | Pronúncia | Armadilha |
|---|---|---|
| ate | êit | não é "áte" |
| said | séd | não é "sáid" |
| bought | bót | o "ough" não soa |
| taught | tót | o "augh" não soa; t normal |
| thought | thót | th surdo (≠ taught) |
| paid | pêid | não é "páid" |
| read (passado) | réd | escreve igual ao presente (ríid) |
| live (verbo) | lív | x live (adjetivo, "ao vivo"): láiv |
| women | UÍ-min | singular woman = UÚ-mân |
| church | tchârtch | sem "i" no fim |
| meeting | MÍI-tin | o g final quase some |
| every | ÉV-ri | 2 sílabas, não "É-ve-ri" |
| comfortable | KÂMF-târ-bâl | 3 sílabas, não "com-for-TÁ-bel" |
