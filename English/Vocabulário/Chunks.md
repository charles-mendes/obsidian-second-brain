# Chunks

Voltar para [[Mapa - Inglês]] · Relacionado: [[Collocations]], [[Word Families]], [[Phrasal Verbs]]

**Chunk** é um bloco de palavras que nativos usam como uma unidade pronta. Em vez de montar a frase palavra por palavra:

> **I + want + to + know**

você aprende o bloco inteiro:

> **I want to know...** = "Eu quero saber..."

Isso deixa a fala mais rápida e natural, porque o cérebro busca o bloco pronto em vez de construir a frase do zero.

## Conversa do dia a dia

| Chunk | Significado |
| --- | --- |
| **How's it going?** | Como vão as coisas? |
| **What have you been up to?** | O que você tem feito? |
| **Let me see...** | Deixa eu ver... |
| **Give me a second.** | Me dá um segundo. |
| **By the way...** | A propósito... |
| **I'm used to...** | Estou acostumado a... |
| **It turns out that...** | Acontece que... / Descobriu-se que... |
| **As soon as possible.** | O mais rápido possível. |

## Resolvendo problemas

| Chunk | Significado |
| --- | --- |
| **I'm trying to...** | Estou tentando... |
| **It doesn't work.** | Não funciona. |
| **I'm having trouble with...** | Estou tendo problema com... |
| **What's the issue?** | Qual é o problema? |
| **Let's figure it out.** | Vamos descobrir / resolver. |
| **It should work now.** | Deve funcionar agora. |

## Como estudar

1. Escolha 5 chunks por dia (da tabela ou da planilha).
2. Crie uma frase **sobre a sua vida** com cada um.
3. Fale as frases em voz alta e coloque no flashcard (ver [[Método de Estudo]]).
