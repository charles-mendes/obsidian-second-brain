# Phrasal Verbs

Voltar para [[Mapa - Inglês]] · Relacionado: [[Chunks]], [[Collocations]], [[Word Families]]

**Phrasal verb** é um verbo + partícula (*up*, *out*, *off*, *on*...) que forma um sentido novo, muitas vezes impossível de deduzir pelas partes. Nativos usam phrasal verbs o tempo todo na fala informal, por isso são essenciais para entender conteúdo nativo (etapa B2 → C1 do [[Roteiro B1 ao C2]]).

> [!info] Separáveis × inseparáveis
> - **Separáveis:** o objeto pode ficar no meio → *turn the light off* / *turn off the light*. Com pronome, o objeto **sempre** fica no meio: *turn it off* (nunca *turn off it*).
> - **Inseparáveis:** o objeto vem sempre depois → *look after the kids*.

## Dia a dia

| Phrasal verb | Significado | Exemplo |
| --- | --- | --- |
| **wake up** | acordar | *I wake up at 6 a.m.* |
| **get up** | levantar-se | *I got up late today.* |
| **find out** | descobrir (uma informação) | *I found out the store was closed.* |
| **look for** | procurar | *I'm looking for my keys.* |
| **look after** | cuidar de | *Can you look after my dog?* |
| **give up** | desistir | *Don't give up now.* |
| **go on** | continuar | *Please, go on.* |
| **come back** | voltar | *I'll come back tomorrow.* |
| **pick up** | buscar / pegar | *I'll pick you up at 8.* |
| **run out of** | ficar sem | *We ran out of coffee.* |
| **catch up** | colocar o papo em dia / alcançar | *Let's catch up next week.* |
| **turn on / turn off** | ligar / desligar | *Turn off the TV.* |

## Trabalho e tecnologia

| Phrasal verb | Significado | Exemplo |
| --- | --- | --- |
| **figure out** | descobrir, entender como resolver | *I need to figure out why the build fails.* |
| **set up** | configurar, montar | *Let's set up the database.* |
| **roll out** | lançar gradualmente | *We'll roll out the feature next week.* |
| **roll back** | reverter (deploy) | *We had to roll back the release.* |
| **break down** | quebrar / dividir em partes | *Let's break down this task.* |
| **look into** | investigar | *I'll look into the issue.* |
| **follow up** | dar seguimento | *I'll follow up by email.* |
| **come up with** | ter (uma ideia), propor | *She came up with a great solution.* |
| **carry out** | executar, realizar | *We carried out some tests.* |
| **back up** | fazer backup / apoiar | *Back up your files before updating.* |
| **sign up** | cadastrar-se | *Sign up for the beta.* |
| **log in / log out** | entrar / sair (sistema) | *I can't log in.* |
| **scale up** | escalar, aumentar | *We need to scale up the servers.* |
| **shut down** | desligar / encerrar | *They shut down the old service.* |
| **point out** | apontar, destacar | *He pointed out a bug in my code.* |

## Negócios

| Phrasal verb | Significado | Exemplo |
| --- | --- | --- |
| **start up** | abrir (empresa) | *He started up a SaaS company.* |
| **take off** | decolar, fazer sucesso | *Sales really took off.* |
| **pay off** | valer a pena / quitar | *The hard work paid off.* |
| **cut back on** | reduzir (gastos) | *We need to cut back on expenses.* |
| **set aside** | separar, reservar | *Set aside 10% of your income.* |
| **build up** | acumular, construir aos poucos | *Build up an emergency fund.* |
| **sell out** | esgotar | *The product sold out in a day.* |
| **go under** | falir | *Many startups go under in the first year.* |

## Como estudar

1. Aprenda sempre com uma frase de exemplo, nunca isolado.
2. Agrupe por partícula para perceber padrões: **up** costuma indicar aumento ou conclusão (*build up*, *set up*), **out** indica descoberta ou saída (*find out*, *figure out*, *run out*).
3. Procure os phrasal verbs nos vídeos que você assiste e anote os novos aqui.
